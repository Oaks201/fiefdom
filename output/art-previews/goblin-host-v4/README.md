# Goblin Host portrait revisions

Review concepts only. No game assets or manifest entries were changed for this revision.

- **Hired Ogres:** Removed the eye mark, added a bared-teeth grimace and high ponytail. Kept the slate-gray ogre face and hired-coin sash.
- **Slingers:** Added brass scope goggles with an extended telescopic lens. Kept the sling, hood, and scarf.
- **Trap-setters:** Replaced the old bulky coat and chest device with a dark teal quilted jerkin, russet leather harness, cord and pouches, and a folded trap carried behind the shoulder. Kept the face and single goggle.
- **Trap-setter nose:** Sharpened the rounded nose into the longer, downturned goblin shape used across the host; the field-trapper outfit remains.
- **Sneaks and The Golden Guard:** Source files are byte-identical to the approved `goblin-host-v2` versions.

`prepare.cjs` exports 512×512 portraits, 128×128 map tokens, 48×48 icons, and a contact sheet from the transparent sources.
