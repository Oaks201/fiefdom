# Dwarf Host concepts

Review concepts only. No game assets or manifest entries were changed.

- **The Anvil Guard:** The tall ornate shield has a slight, coherent three-quarter angle inspired by the user's shield-pose reference. The anvil stays aligned with the shield face and fully visible; the bottom remains cropped offscreen. The winged closed helmet, gray beard, shoulder crop, and weaponless silhouette remain.
- **Thunderers, Ironbreakers, Rune Priests, and Hammerers:** Source art is byte-identical to `dwarf-host-v10`.

`prepare.cjs` exports 512×512 portraits, 128×128 map tokens, 48×48 icons, and a contact sheet from the transparent sources.
