## Notes for the owner

- **Fitbit tokens off Windows.** `healthIpc.ts` encrypts tokens with `safeStorage` when the OS offers it and otherwise stores them in plain text beside the ledger. Windows (DPAPI) always offers it, so the release this audit covers is fine; a macOS or Linux build without a keychain would not be.
- **A3 must keep the "Shame" row true.** The lines above are placeholders; the written text replaces them, and the Healer's lines show only once marked approved (`text.test.ts`). Reading the final text against this row is part of A3.
