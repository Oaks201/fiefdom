# Sellswords portrait and token

Approved on 2026-10-10. The Merchant Hall Tier II Sellsword visually grows from the Watchman: the same older salt-and-pepper-haired face, gray mustache, ochre hood and guarded expression, now with a worn eyepatch, healed scars, short stubble, sword, and battered mercenary armor. The round coin charm remains; there is no coin pouch.

The [approved source](portrait-source.png) was made with the built-in image generator through the [first Sellsword concept](../../../../output/art-previews/tier-ii-companies-v1/sellswords-source.png) and [eyepatch revision](../../../../output/art-previews/sellswords-v2/portrait-source.png). The [prompt record](../../../../output/art-previews/sellswords-v3/prompt.md) and [comparison gallery](../../../../output/art-previews/sellswords-v3/index.html) preserve the iteration.

The installed files are `company.sellswords.portrait-revised-v4.png` (512 × 512) and `company.sellswords.token-revised-v4.png` (128 × 128) in `src/renderer/public/game-assets/`. Both come from a 256 × 256 contained logical image with nearest-neighbor resizing and preserved transparency. Acolyte and Crossbowman remain preview-only concepts.
