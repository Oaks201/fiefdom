Generated by `npm run sim -- --targets` (`sim/targets.ts`); do not edit by hand. 460 campaigns: Perfect, Steadfast, Committed and Wavering with the greedy player (40 seeds each), Steadfast steered along one path (each rival), two (Orc and Goblin; Dwarf and Archmage), three, and all four, and the smarter Steadfast player, unsteered and along each one path (70-week horizon; 380 s).
