# The blueprint's targets, rules 3.1.0

Generated by `npm run sim -- --targets` (`sim/targets.ts`); do not edit by hand. 340 campaigns: Perfect, Steadfast, Committed and Wavering with the greedy player (40 seeds each), and Steadfast steered along one path (each rival), two (Orc and Goblin; Dwarf and Archmage), three, and all four (70-week horizon; 330 s). The targets are `docs/redesign/blueprint.md` section 7; "Steadfast" is its greedy player, and the focused player follows one rival's path. G-01 and G-03 are counted as `docs/redesign/patch-3-spec.md` C-27 rules: a Breach day (a repulse that left its target within the next day's reach) is player-view meaningful, and a target is a hex that falls within 3 assault days; the strict readings are given beside them.
