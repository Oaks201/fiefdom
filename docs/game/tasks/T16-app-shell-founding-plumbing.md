## Goal

Put the campaign into the app: new pages in the navigation, a founding wizard, the Herald's dawn tidings, a Homecoming screen after an absence, and the campaign purse in the top bar. Build the **art and text plumbing** every screen uses, so the game runs fully on placeholders and the owner can drop real art and writing in at the end with no code changes. Also add dev-only time travel, so every later screen can be checked across days.

## Scope

1. **Navigation.** Add Realm, Diplomacy and Armory pages (empty shells that T18, T19 and T14 fill). The Battle screen opens from a Grand Battle notice; it is not a tab. Ctrl+1 to 6 switch pages. The new pages appear only once a campaign exists. The ledger-only app behaves exactly as it does today until then.
2. **The founding wizard** (a modal, in steps):
   - Weight: start (pre-filled from the latest weigh-in), goal, unit, target-pace cap 0.3 to 1.0 (default 0.8).
   - Optional height, sex and birth year, with a plain note that they are used only to estimate the Healer's calorie floor.
   - The Charter: step pool, calorie limit (validated against the Healer floor, with the floor shown), and 1 to 5 duties, offering the Ch 16 additive suggestions.
   - Confirm: the time zone is shown, and founding takes a hold on a wax seal.
   - Refusals: a legacy contract is open (A-07); a goal below BMI 18.5 when a height is given; a calorie limit below the floor.
   - Calls `foundCampaign` and saves `campaign.json`.
3. **The top bar,** once a campaign exists: the purse (whole number, A-11), Realm Consistency (28 days), and the Grace level as its plain description. Legacy reputation moves to the Archive.
4. **The Herald:** a tidings panel used by the Chronicle and the Realm page, showing today's threats, their targets and strength bands (exact only when unlocked), rival rumors, Grand Battle warnings, and yesterday's results, all from `combat.tidings` and the event log, all text through `t()`. In-app only; there are no OS notifications or tray (D-04).
5. **Homecoming:** shown at launch when `settle` caught up 3 or more days or the player was away 14 or more days (A-45). It says plainly what held, what was lost and the purse change, and the Steward suggests a short contract. The tone is chronicle, not judgment (Ch 16).
6. **Art plumbing (the A-08 paths):**
   - `src/renderer/public/game-assets/manifest.json` maps each slot id to `{ file: string | null, kind, size: [w, h] }`.
   - Generate the slot inventory from the codex plus the fixed lists in the Ch 17 asset table: hex terrains and overlays; 20 building tiers; 5 castle tiers; 12 rival portraits (4 rivals × calm, angry, humbled); a token and a portrait per company line; Elite, mythic, Dragon and Wild Hunt portraits; item icons; 6 banners; an event card per event; 10 Milestone scenes; the interface kit.
   - `<GameArt slot="…" />` renders the file when it is listed and present. Otherwise it draws a placeholder: a hex in the owner's banner color (from the Ch 17 color table), a lettered token, initials on a parchment card. A missing file must never throw.
   - `npm run assets:check` (`scripts/check-assets.cjs`, no new dependencies; read PNG and WebP dimensions from the file header) prints missing slots, unknown files and wrong sizes. It exits 0 in report mode and 1 with `--strict`.
   - `docs/game/assets.md` is generated by the same script: a checklist table of every slot with its file name, size and where it shows. This is what the owner works from in A2.
7. **Text plumbing:** a renderer hook `useText()` around `t()`, plus a dev-only overlay that counts placeholder versus final text per catalog file. `npm run text:check` reports which slots are still placeholders and which Healer entries are not approved. It also flags any `{placeholder}` in a `final` that its template doesn't offer, and warns when a `final` runs longer than the Ch 17 length for its slot type (sentence count). A3 relies on these checks.
8. **Sound slots:** new game sound effect ids (battle won, battle lost, Milestone, Herald, and so on) are registered with a silent fallback in `audio/sfx.ts`, so A4 can add files later without code changes.
9. **The big-moment card:** a full-screen painted-card component (placeholder art plus text slots) for Milestones, Grand Battle results, coalitions, victory and the Fall. Other tasks call it.
10. **Dev time travel (A-09):** a dev-only menu to advance a day or a week (which runs `settle`) and to set `FIEFDOM_DEV_NOW`. It is absent from production builds.

## Out of scope

The contents of the Realm, Diplomacy, Battle and Armory pages; final art and text.
